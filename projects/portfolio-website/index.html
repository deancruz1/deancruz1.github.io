Why I built it

My first real website, built during my diploma to learn the fundamentals.

I needed a portfolio for my diploma and wanted to properly learn HTML, CSS and Bootstrap while making it. It was later picked by faculty as the cohort's reference for code structure.

How it works

A multi-page site on the Bootstrap Grayscale theme, with my own JavaScript for the effects.

I started from the Start Bootstrap Grayscale theme and grew it into a multi-page site: a home page, a projects page, and a page for each project with a lightbox gallery. On top of the theme I wrote a mouse trail, a drag-to-scroll image track and a particles.js starfield.

Technical decisions

Start from a theme

The Grayscale theme gave me a working responsive layout, so I could focus on structure and content and learn how a real Bootstrap project is put together.

A mouse trail with easing

A chain of circles follows the cursor, each one easing towards the next on every animation frame. It switches off on touch devices, where there's no cursor to follow.

Drag-to-scroll image track

The track keeps its state in data attributes, moves with the Web Animations API and shifts each image's object-position for a parallax effect. It only runs on wide screens.

Challenges & reflections

  • The drag handler ignores presses that start on a link, so the cards in the track stay clickable, and it clamps the track so it can't be dragged past either end.
  • Next: Load a single Bootstrap version. The home page loads the Bootstrap 5.2.3 and 4.5.2 scripts together.
  • Next: Stop the auto-scroll loop and the drag code fighting over the track. Both set its position on every frame.
