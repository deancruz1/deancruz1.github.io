Overview

SkillForge is an e-learning platform. Instructors create courses, lessons and quizzes, and students enrol, track their progress and get their quizzes graded automatically.

I built it to learn enterprise Java properly: a Spring Boot REST API with Spring Security and JWT, Hibernate over a 9-table PostgreSQL schema, and an Angular frontend.

Problems and fixes

Junction tables needed composite keys.

I mapped them with @EmbeddedId and @MapsId.

Supabase's connection pooler rejected prepared statements.

Setting prepareThreshold=0 fixed it.

Spring Boot had to run on Render.

I wrote a multi-stage Docker build for it.

Every request has to prove who sent it.

A Spring Security filter checks a JWT each time, so sessions stay stateless.

If I picked it back up. Enforce one quiz attempt on the server, and keep answers out of students' API responses.
