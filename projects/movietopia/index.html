Overview

A deep dive into server-side fundamentals. Built to understand how session auth, relational schemas, and CRUD operations fit together end-to-end.

Key features

Database

Three related MySQL tables (users, movies, reviews) with foreign keys.

Accounts

Registration and login, with PHP sessions guarding the review pages.

Reviews

Logged-in users can submit, edit and delete their own star-rated reviews.

Search

A searchable movie list showing genre, director, cast and synopsis.
