Kiroku

An anime tracker with a watch list, seasonal calendar, recommendations and viewing stats.

Live siteCode
Next.jsTypeScriptPrismaPostgreSQLNextAuth

Why I built it

Most anime trackers are fragmented. Users bounce between MyAnimeList for tracking, separate sites for seasonal schedules, and Reddit for recommendations. I wanted one clean app that handled all three without the bloat.

How it works

Built on Next.js App Router with React Server Components, Prisma ORM on Supabase PostgreSQL, and NextAuth v5 for dual authentication with Discord OAuth. The Jikan API drives all anime data. Users track shows with full CRUD, browse a 7-day broadcast calendar, get genre-based recommendations, and view stats in a Spotify Wrapped-style bento dashboard.

What it does

Sign-in

Discord OAuth or email and password, with bcrypt hashing and JWT sessions.

Watch list

Add shows, then update status, episode progress and star ratings inline.

Seasonal calendar

A 7-day broadcast view with episode countdowns and genre filters.

Recommendations

Finds your top genres from watch history and suggests unwatched shows from the Jikan API.

Stats

A bento grid of summary cards and a Recharts donut chart of watch status.

Collections

Create, rename and delete custom lists, and add or remove shows.

Decisions

Next.js App Router

Server components and streaming eliminate unnecessary client-side fetching. Layouts and loading states are built-in.

Jikan API

Free, no API key required, and comprehensive anime data. The rate limit was a real constraint that pushed me to implement proper retry logic.

Supabase PostgreSQL

Vercel serverless functions use ephemeral filesystems. SQLite writes do not persist between invocations.

Vercel

GitHub Pages only serves static files. Vercel supports serverless functions, which are needed to run backend logic and keep API keys out of the client.

Challenges

  • Jikan API enforces a strict 3 requests per second rate limit, so exponential backoff with retry logic was needed to handle request bursts on data-heavy pages without crashing
  • The seasonal calendar required parsing inconsistent broadcast data formats from the API, building countdown timers with timezone awareness, and handling edge cases like missing air times

What I'd do differently

  • Store anime metadata in the database when a user adds a show, eliminating redundant Jikan API calls and reducing rate limit exposure
  • Implement email verification system for new accounts
  • Implement password reset via email for account recovery
