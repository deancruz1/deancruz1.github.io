Why I built it

My first project, made to practise HTML and CSS before my diploma started.

Before enrolling at Republic Polytechnic I wanted a real project to practise on, so I built a fan shrine for a VTuber I enjoy watching, inspired by Lyrenide's Hakurei Shrine.

How it works

Plain HTML, CSS and JavaScript, with the effects done in CSS wherever possible.

A single page in plain HTML, CSS and JavaScript: a sticky blurred header, fixed-background parallax, a glowing call-to-action button, a CSS-only disclaimer modal and a hamburger menu for phones. I later refactored the HTML and CSS to make it easier to maintain.

Technical decisions

CSS before JavaScript

The modal, the glowing button and the parallax are all CSS. JavaScript only toggles the hamburger menu.

Fluid type with clamp()

Font sizes grow and shrink with the screen between a minimum and maximum, so fewer media queries are needed.

Animated nav links

On hover, a border scales from 10% to full width while the letter spacing opens up.

Challenges & reflections

  • Fading the modal in and out meant hiding it with visibility and opacity instead of display, since display can't be transitioned.
  • Next: Restore the disclaimer text inside the modal. The refactor left the modal empty.
  • Next: Open the external links in the mobile menu in a new tab, like the desktop ones.
