// HANDLER ONE

A fansite for 86 Eighty-Six, styled as a Handler's military terminal with dossiers, mech specs and a combat log.

Live siteCode
ReactTailwind

About

The concept is simple: you're a Handler logged into HQ. The site covers the full series: plot breakdowns by act, Spearhead Squadron dossiers with Para-RAID sync status, a mech database with armament specs, faction geopolitical profiles with threat classifications, and a combat log archive across all episodes.

What it does

Series archive

Plot breakdowns by act, a mech database, faction profiles and a combat log.

Terminal UI

CRT scanline overlays, vignette effects and alert themes that change with operational status.

Processor dossiers

Cards with sync rates, operational history and Para-RAID status for each Spearhead member.

Deep links on GitHub Pages

A 404.html interception script makes refreshes and direct links work on static hosting.

Responsive layouts

Desktop terminal grids that collapse into mobile screens.

Data structure

Processor dossiers kept separate from the unit insignia and mecha asset mappings.
